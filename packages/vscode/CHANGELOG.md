# Changelog

## 0.1.0

- Syntax highlighting for `.navgraph`.
- Live validation with line and column, using the same parser and validator as the library.
- Hover and go to definition for screens and `$VARIABLES$`, document outline, completions for actions, screen ids and variables.
- Interactive graph preview with route highlighting.
- Commands: Open Graph Preview, Find Route Between Screens, Copy Route Instructions as JSON.
- Schema validation for `.navschema` files.
